# Marketing Knowledge Base

This repository is a read-only copy of a marketing knowledge base -- verified, source-backed frameworks, principles, playbooks, and schemas, organised under `knowledge/`.

## If you're an AI agent

Read [AGENTS.md](AGENTS.md) before answering any question using this repository. It has your full operating instructions -- how to navigate this content, how to talk to the user, and what to check before you answer. Nothing here works correctly without it.

## If you're a person

Browse `knowledge/frameworks/`, `knowledge/playbooks/`, `knowledge/principles/`, and `knowledge/schemas/` directly, or start from `kb/kb-entrypoints.md` for a curated route into a specific topic (positioning, pricing, segmentation, and more).
