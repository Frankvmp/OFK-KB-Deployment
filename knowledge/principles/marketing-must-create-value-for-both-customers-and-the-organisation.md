# Marketing must create value for both customers and the organisation

## When to use this

Reach for this Principle when a marketing choice benefits customers but weakens the organisation's return, or extracts value while making the customer offer unsustainable.

## Principle

Marketing has two simultaneous value obligations: create value for the market and create value for the organisation. Neither side can be treated as the sole objective.

The exchange fails when the organisation extracts too much from customers, but it also fails when the organisation gives customers value without retaining enough to support the business. The two sides must remain aligned.

## Why it matters

This Principle prevents customer value and company value from becoming competing slogans. A viable marketing decision must account for both sides of the exchange.

## Related distinctions

Customer value is not the same as low price. Organisational value is not the same as revenue alone. Pricing is one mechanism through which the organisation harvests part of the value it has created.

## Boundaries and failure modes

- Do not maximise extraction at the expense of a credible customer offer.
- Do not maximise customer giveaway without considering the organisation's return.
- Do not treat one side of the value exchange as a substitute for the other.
