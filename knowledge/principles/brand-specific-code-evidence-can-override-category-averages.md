# Brand-specific code evidence can override category averages

## When to use this

Reach for this Principle when general research suggests a type of brand code is weak but the focal brand may possess an unusually strong example.

## Principle

Category-level evidence can show how code types perform on average, but an average does not determine the value of a specific brand asset.

A code that customers strongly and uniquely associate with the focal brand may remain valuable even when its code type performs poorly on average. The decision should follow brand-specific evidence.

## Why it matters

Applying an average mechanically can discard an established asset whose actual performance differs materially from the category pattern.

## Related distinctions

General benchmarks inform the prior expectation. Brand-level testing determines whether the specific asset is an exception.

## Invokes

- [Positioning and brand codes](../frameworks/positioning-and-brand-codes.md) (Framework) — assesses candidate assets through fame and brand-specific association.

## Boundaries and failure modes

- Do not reject a code solely because its type has a weak average.
- Do not claim an exception without brand-specific evidence.
- Use the general benchmark when no stronger focal-brand evidence exists.
